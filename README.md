# House Price Predictor (Streamlit)

```bash
pip install -r requirements.txt
streamlit run app.py
```

Files: `app.py`, `final_house_price_gb_model.joblib` (tuned Gradient Boosting pipeline),
`House_price.csv` (training data), `requirements.txt`.

Note: the model was saved with scikit-learn 1.6.1, so that version is pinned.
